# ⚡ Billing Automation

Инструмент для автоматического распределения лицензий IT-сервисов по ЦФО (центрам финансовой ответственности).


---

## Быстрый старт

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Запустить
streamlit run app.py
```

Приложение откроется в браузере по адресу `http://localhost:8501`.

### Требования

- Python 3.8+
- Библиотеки: `streamlit`, `pandas`, `openpyxl` (устанавливаются из `requirements.txt`)

---

## Как работать

### 1. Загрузка файлов (боковая панель)

В боковой панели слева загружаются все исходные файлы:

- **Справочник сотрудников** — файл `Список_сотрудников.xlsx` из 1С. Из него берётся ник (столбец A, с очисткой старых ников в скобках) и ЦФО (столбец C, если пустой — подставляется «ПП НЕО»).
- **Файлы сервисов** — выгрузки из каждой системы. Для каждого сервиса своё поле загрузки.

После загрузки файл сразу парсится, в основной области показывается количество найденных пользователей.

### 2. Вкладка «Отчёт»

Основная рабочая область. Здесь:

- **Статистика** — сколько сотрудников в справочнике, сколько ЦФО, сколько сервисов загружено, и краткая сводка по каждому сервису.
- **Ненайденные пользователи** — раскрывающийся блок со списком ников, которых нет в справочнике. Можно отфильтровать по сервису. Есть массовое назначение ЦФО (выбрал ЦФО → «Назначить» — применится ко всем отфильтрованным) и индивидуальное назначение через выпадающий список.
- **Кнопки генерации**:
  - **📊 Сформировать** — строит отчёт и показывает его в виде вкладок прямо в приложении (Общая сводка, User list, Pivot по каждому сервису, Не найдены, Доп DB, DB Users, Для финансов).
  - **⬇️ Excel (общий)** — скачивает тот же отчёт в `.xlsx`.
  - **📁 По отделам (ZIP)** — скачивает ZIP-архив, внутри папка на каждый ЦФО с двумя файлами: HTML-отчёт и XLSX в формате для финансов.

### 3. Вкладка «Параметры»

- **Цены за лицензию** — текстовые поля для каждого сервиса (₽). Цены сохраняются в файл `service_prices.json` и используются в Pivot-таблицах, общей сводке и отчётах по отделам.
- **Тема HTML-отчётов** — акцентная тема в стиле фирменного брендбука (Montserrat, фиолетовый акцент).

### 4. Вкладка «Доп DB Users»

Таблица всех вручную назначенных пользователей с привязкой к сервисам. Можно очистить все назначения кнопкой «Очистить все».

## Поддерживаемые сервисы

| Сервис | Формат | Откуда берётся ник |
|--------|--------|--------------------|
| Google Workspace | CSV / XLSX | Столбец B (`Last Name [Required]`) |
| Miro | CSV / XLSX | Последнее слово из столбца A (`Name`) |
| GitHub | XLSX (1-я вкладка) | Столбец F (`GitHub com saml name ID`), фоллбэк на столбец A (`login`) |
| GitHub Copilot | XLSX (2-я вкладка) | Столбец C (`SAML Name ID or Email`) |
| M365 | XLSX (вкладка `Licenses by user`) | Последнее слово из столбца A (`User`), фильтр SKU = `SPE_E3` |
| Power BI | XLSX (вкладка `Licenses by user`) | Последнее слово из столбца A (`User`), фильтр SKU = `POWER_BI_PRO` |
| Mattermost | CSV / XLSX | Столбец A (`NickName`) |
| TestIT | CSV / XLSX | Столбец A (`Nickname`) |
| 1С Лицензии | XLSX | Столбец A (`ФизЛицо`) с очисткой скобок |
| Jira + Confluence | XLSX | Столбец A (`ФизЛицо`) с очисткой скобок |

## Формат выходных файлов

### Общий Excel-отчёт

| Лист | Содержание |
|------|-----------|
| Общая сводка | Таблица ЦФО × сервисы (количество лицензий) + строка стоимости |
| User list {Сервис} | Построчно: Nickname, ЦФО |
| Pivot {Сервис} | Сводка: ЦФО → количество, %, стоимость |
| Не найдены | Ники без совпадения в справочнике |
| Доп DB {Сервис} | Вручную назначенные пользователи по сервисам |
| DB Users | Полный справочник (основной + доп.) с колонкой «Источник» |
| Для финансов | Все пользователи в формате: Продукты ТХ, Nickname, Потребитель, Единица продукта, Количество, Цена, Стоимость, Комментарий, Свободное поле |

### Отчёты по отделам (ZIP)

Для каждого ЦФО — папка с двумя файлами:

- **HTML** — красивый отчёт с таблицей сервисов. Клик по сервису раскрывает список пользователей. Итого — только стоимость.
- **XLSX** — данные в формате для финансов (столбцы как в листе «Для финансов»).

## Хранение данных

Приложение сохраняет настройки между сессиями в двух файлах рядом с `app.py`:

| Файл | Содержание |
|------|-----------|
| `extra_db_users.json` | Вручную назначенные пользователи (ник → ЦФО + список сервисов) |
| `service_prices.json` | Цены за лицензию по сервисам |

Эти файлы можно безопасно удалить — приложение создаст их заново при следующем назначении.

## Передача другому пользователю

Чтобы передать приложение коллеге:

1. Скопировать папку `billing-app` (или клонировать репозиторий)
2. Установить Python 3.8+
3. Выполнить `pip install -r requirements.txt`
4. Запустить `streamlit run app.py`

Файлы `extra_db_users.json` и `service_prices.json` можно включить в передачу — тогда у коллеги будут те же доп. пользователи и цены.
